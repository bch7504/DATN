# Admin routes

Dashboard, users/roles, Subject/Semester, Course Offering monitoring, feedback, audit và settings. Không có Teacher assignment hoặc màn quản trị AI/vector.

Khu vực Admin không dùng fixture hoặc số liệu hard-code. Dashboard và danh mục chỉ hiển thị dữ liệu lấy từ Java Backend; chức năng chưa có public Admin API phải hiển thị trạng thái rỗng/lỗi rõ ràng, không mô phỏng dữ liệu hay thao tác thành công.

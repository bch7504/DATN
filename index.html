02 · Product scope

Hai không gian, một nền tảng

Student tự quản lý việc học. Admin vận hành hệ thống và nội dung chuẩn, không can thiệp tiến độ cá nhân.

03 · System design

Kiến trúc tách trách nhiệm

Next.js phục vụ trải nghiệm; Spring Boot giữ nghiệp vụ và dữ liệu; Python AI Service xử lý tài liệu, RAG và sinh quiz qua internal API.

Nguyên tắc phân lớp

Java giữ domain logic và database; Python AI là service chuyên biệt, giao tiếp qua hợp đồng nội bộ.

1Web chỉ gọi Java backend, không gọi thẳng AI service.
2Spring service chứa luật nghiệp vụ có thể unit test.
3Python AI chỉ trả kết quả/citation, không cập nhật mastery.
4Request ID nối log xuyên suốt Web → Java → Python.

# Student Course Offerings

Join code, Enrollment status và danh sách Course Offering theo học kỳ. Chỉ enrollment `APPROVED` mở được chi tiết lớp.

Trong mỗi lớp học phần, Student chuyển giữa hai khu vực:

- Học liệu lớp học: Slide chỉ xem trong Viewer và hỏi đáp AI; PDF tham khảo chỉ tải xuống.
- Bài tập về nhà: yêu cầu, hạn nộp, trạng thái bài làm và đường dẫn đến màn hình nộp bài đúng lớp.

Hai khu vực này không còn là mục điều hướng Student độc lập. Dữ liệu đều lấy từ Java API, không dùng fixture hoặc số lượng giả.

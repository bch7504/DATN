Product scope

Một nền tảng, ba không gian làm việc

MVP tập trung vào quản lý học liệu, hoạt động học và ôn tập. AI trả lời theo hai ngữ cảnh và sinh Quiz từ Personal Document đã được kiểm quyền.

S

Student learning flow

Nhập join code, chờ duyệt Enrollment rồi học Slide, dùng chatbot, lịch và Quiz.

  • Course Offering + Enrollment
  • Slide Viewer + Note + Tutor
  • Personal RAG + Quiz draft
T

Teacher ownership flow

Tự tạo Course Offering, duyệt Student và public file vào đúng lớp mình sở hữu.

  • Join code + Enrollment
  • PDF/PPTX library
  • Public / revoke
A

Admin governance flow

Quản lý user, Subject/Semester và giám sát lớp; không phân công từng lớp.

  • RBAC và account status
  • Course Offering monitoring
  • Feedback, logs, settings

Frontend chỉ gọi Java; Java tiếp tục kiểm tra enrollment `APPROVED` và trạng thái publication trước khi gọi Python AI service. Ghi chú theo trang và theo dõi tiến độ chưa được nối trong luồng này; không thay bằng nội dung mẫu.

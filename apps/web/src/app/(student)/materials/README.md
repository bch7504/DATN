# Student materials

Course Material chỉ dùng PDF có text layer. Student xem danh sách các Course Offering đã được duyệt trước; sau khi chọn lớp chỉ xem/tải tài liệu được công bố cho lớp đó. Java tiếp tục xác thực enrollment `APPROVED`. Ghi chú theo trang, theo dõi tiến độ và AI Tutor chưa được nối trong luồng này; không thay bằng nội dung mẫu.

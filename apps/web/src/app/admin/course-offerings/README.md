# Course Offering Monitoring

Admin xem yêu cầu mở lớp ngay trong Lớp học phần, chọn môn chuẩn có sẵn hoặc chuẩn hóa mã/tên/tín chỉ được đề xuất rồi duyệt; từ chối cần lý do. Java tạo lớp cho đúng Teacher trong một transaction và ghi audit. Phần lớp đang hoạt động vẫn có giám sát, khóa và lưu trữ.

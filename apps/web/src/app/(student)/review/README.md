# Ôn tập và quản lý Quiz

Student chọn Course Offering hoặc Quiz cá nhân, tạo Quiz từ Personal Documents bằng prompt tự do, review/regenerate, chọn nơi lưu khi accept, làm Quiz `READY`, xem câu sai kèm citation và so sánh lịch sử attempt.

Frontend không tự chấm điểm; kết quả submit lấy từ Java public API.

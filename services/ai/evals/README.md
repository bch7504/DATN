# AI evaluation

Chứa dữ liệu tổng hợp cho ba eval suite tách biệt:

- Personal RAG: owner/document isolation, retrieval relevance, groundedness và citation correctness.
- Slide Tutor: đúng document/slide scope, groundedness, citation correctness và latency.
- Quiz generation: schema hợp lệ, đáp án duy nhất, giải thích phù hợp và nguồn chỉ thuộc Personal Document được cấp quyền.

Không đặt tài liệu cá nhân hoặc nội dung production trong thư mục này.

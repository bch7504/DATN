# Student materials

Course Material chỉ dùng PDF có text layer. Student có enrollment `APPROVED` được xem/tải file đã công bố và dùng AI Tutor theo trang ngay cạnh trình xem PDF. Frontend gọi Java; Java kiểm tra enrollment/publication rồi mới gọi Python AI service. Ghi chú theo trang và theo dõi tiến độ chưa được nối trong luồng này; không thay bằng nội dung mẫu.
